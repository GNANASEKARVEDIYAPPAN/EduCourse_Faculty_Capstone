## 1. Project Overview

EduCourse is a web-based Course Design and Automation platform developed to support faculty members in planning, organizing, and managing academic course-related activities.

The application provides a centralized interface for accessing course design modules, managing educational content, and supporting academic documentation.

## 2. Project Objectives

- Simplify academic course design and planning.
- Reduce repetitive faculty documentation work.
- Provide a centralized course management dashboard.
- Support structured academic content development.
- Integrate Python-based backend processing with web technologies.
- Establish a foundation for AI-assisted educational automation.

## 6. Installation and Execution

### Step 1: Clone Repository

```bash
git clone https://github.com/GNANASEKARVEDIYAPPAN/EduCourse_Faculty_Capstone.git
```

### Step 2: Open Project Directory

```bash
cd EduCourse_Faculty_Capstone/educourse
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run Application

```bash
python app.py
```

Open the local URL displayed in your terminal to access the application.

## 7. Application Workflow

1. Faculty accesses the login interface.
2. The application displays the dashboard after successful authentication.
3. Faculty selects the required course design module.
4. The selected module displays its corresponding academic content.
5. Course-related information can be processed through the available application components.
